# Frontend (app/)

Expo SDK 52 / React Native 0.76 + TypeScript, Android only, version 0.3.0 (versionCode 3; round 2 built + tested 2026-11-18 on the emulator; the emulator dev build was rebuilt with `expo-clipboard`). Backend contract: backend.md. Type-check: `cd app; node node_modules/typescript/lib/tsc.js --noEmit` (the `&` in the path breaks `npx` under cmd).

## Run
1. `cd app; npm install`. Server running (backend.md). Server URL: `EXPO_PUBLIC_SERVER_URL` env, else `app.json` `extra.serverUrl` (live HTTPS URL), else `http://10.0.2.2:3000` (emulator -> host PC). Release APK blocks plain `http://`. Read in `src/config.ts`; WebSocket URL derived (http -> ws).
2. Dev build (needed for voice + foreground service; Expo Go works without them): map a drive (the `&` breaks Gradle/Metro): `subst T: 'd:\r&D\team-app'`, then `cd T:\app`; Metro: `EXPO_PUBLIC_SERVER_URL=http://localhost:3000 npx expo start --dev-client --localhost --port 8081`; per device `adb -s <serial> reverse tcp:3000 tcp:3000` + `reverse tcp:8081 tcp:8081`. Native rebuild only when a native dependency/plugin/app.json native field changes: `node node_modules/expo/bin/cli prebuild --platform android --clean` (restore package.json scripts afterwards), then `cd android; .\gradlew.bat assembleDebug '-PreactNativeArchitectures=x86_64,arm64-v8a'` with `JAVA_HOME=D:\Android\jdk17`, `ANDROID_HOME=D:\Android\Sdk`, `GRADLE_USER_HOME=D:\Android\gradle`; install `adb -s <serial> install -r app/android/app/build/outputs/apk/debug/app-debug.apk`. Release APK: DEPLOY.md.
3. Emulator AVD `teamchat_test` (`server/scripts/emulator-start.ps1`); real tab serial `de4eaf03`; always pass `-s`.
4. Keep react-navigation on the SDK 52 pins in package.json (`overrides`). Add native packages only with `expo install` and tell the owner (rebuild needed). `expo-clipboard` powers "Copy" (emulator dev build rebuilt 2026-11-18; the tab's dev build and the release APK still need the rebuild); a build without it falls back to the Android share sheet (`copyText` in `src/dates.ts`).

## Structure
- `App.tsx` (tab bar hides while the keyboard is open): SafeAreaProvider > AuthProvider > Root: update gate (`UpdateScreen` when forced), spinner, LoginScreen, or tabs Chats | Tasks | Admin ("Account" for members); `UpdateBanner` and the root `InAppBanner` (mentions / ask / answered while that chat is not open) float on top.
- Core `src/`: `config`, `version` (VERSION_CODE/NAME, keep = app.json), `api` (Bearer token + `X-App-Version`; `ApiError(message,status,code)`; a 426 flips the update gate), `auth` (kick on SESSION_REPLACED: "Aap kisi aur phone par login ho gaye" + logout; `updateMe`), `sessionStore`, `userStore` (id -> name/emoji from GET /users?includeSelf=1, live on ws `user`; `useUser`, `useUsers`), `bannerStore`, `realtime` (ws `/?v=<code>` with `Authorization` header, falls back once to `?token=`; 4409/4401 kick, 4426 update gate, no reconnect loop; events coalesced every 50 ms), `outbox`, `push`, `background`, `useLive`, `useTheme`, `theme`, `chatTypes`, `taskTypes` (6 steps + closed, labels/colors incl. legacy in_progress/review, assignees, BriefTask, permission helpers), `taskEvents` (timeline text/icons), `commands` (slash command list), `publicSettings` (GET /settings/public cache, refreshed on ws `settings`), `updateStore` (GET /app/version + force-update state), `checkinStore`, `useVoiceInput`.
- `src/screens/`: Login, Chats (hosts list | chat | new | info | task views itself, no stack navigator), Chat, NewChat (dm / group / add members), GroupInfo (= chat info for group / All Team / DM), Tasks (Overview/Board/List + detail view), TaskDetail, Admin, Settings, Reports (+CheckinSettingsScreen).
- `src/components/`: Bubble, BotCard, SystemPill, RichText, Sheet (+SheetRow), Suggestions, ComposerSheets (CommandSheet, PeopleSheet (+Me, multi), PersonSheet), ChatRow, Avatar (+AvatarStack; emoji via `userId`), Chip, StatusPill, StatusChips (6 steps), TaskRow, BriefRow, TaskModal (create, multi-assignee, Me first), TaskActionSheet (quick actions on one task), PeoplePickSheet (multi-select people), TaskAttachment (card under its source bubble), DmTasksSheet, InAppBanner, ProfileSheet (name + emoji), TaskOverview, TaskBoard, TodayPanel (MyDayPanel, SignoffPanel, StalePanel), MyDay (sign-off form), UpdateScreen (+UpdateBanner), CheckinCard, VoiceBar, SwipeReply, Tick, BackgroundCard.

## Screens and features
- **Chats list**: search, All Team, unread badge (grey if muted), pinned chats first (pin icon), mute icon. Long-press a row -> sheet Pin/Unpin, Mute/Unmute (`PATCH /chats/:id/me`). "+" -> new chat / group. Reloads on ws `message|deleted|chat`.
- **ChatScreen**: inverted FlatList (empty state must NOT be flipped by the app: VirtualizedList already flips it). Tap header (group / All Team / DM) -> chat info. Group / All Team: segmented **AI | All | Chat** filter (refetch with `kind`; in AI mode my own just-sent messages stay visible until the filter changes); in All, bot cards with a loaded `sourceMessageId` render attached under the source bubble (TaskAttachment), else standalone. Text messages with `taskId` show a `#N` chip (tap = TaskActionSheet). DM: a clipboard button replaces `@` -> DmTasksSheet (Shared / Unke tasks, + Naya task). Unsent text is kept per chat (memory). Prop `focusId` (ask banner, notification, "Chat mein dekho") scrolls to that message once loaded. Chained sheets (command -> people picker) open 350 ms apart (Android drops a Modal shown while another fades out). Pinned-message bar under the header (tap = scroll to it if loaded). Date separators, "N unread messages" divider (from `chat.myLastRead`, set at open), jump-to-bottom button with unread-while-scrolled count. Ticks, typing, paging up, swipe-to-reply, voice mic.
- **Bubbles**: DMs unchanged (green/white). Group / All Team: incoming bubbles get a subtle tint of the sender color + 3px colored left edge, name in the strong color (`theme.ts`: 12 colors, `tintFor(id, dark)`). Reaction chips under the bubble (tap toggles mine; `POST /messages/:id/reactions`, ws `reaction`). `RichText`: URLs and phone numbers open via Linking, `@Name` bold accent (link blue on my own bubbles for contrast; my name highlighted). `visibleTo` messages show "Only visible to you". `type 'system'` = `SystemPill` (centered grey).
- **Long-press menu** (`Sheet`): reactions, Reply (also on task / ask cards), Copy, **Edit** (own text message < 10 min: text goes back into the composer with an "edit" bar, send = `PATCH /messages/:id`), Pin/Unpin (any member, any non-ephemeral message incl. bot / check-in cards), Message privately, Make task (`/task @Name ` with the id kept), **Delete** (own text < 10 min, also for the admin; or my own "only visible to you" card). Items hide after 10 min (server enforces). Bubbles show "edited" (`editedAt`); ws `edited` updates in place.
- **Composer**: small `/` and `@` buttons left of the input (hidden in check-in chats / when commands are off); mic/send right. Focused empty input -> chip row `/task /update /done /mytasks @ person`. `/` -> CommandSheet (icon + hint); `/task` chains into a multi-select PeopleSheet ("Me (khud)" first; bug 1 fix) and `/tasks` into the PeopleSheet, `#`-commands insert `/cmd #` and show tasks (my open tasks; `/ask #` lists others' open tasks), `/assign` `/unassign` `/reassign #id` then chain into the PeopleSheet (multi, Me included), `/due #id ` shows date chips. `@` -> PeopleSheet (search, avatar, name, phone tail, chat members first) -> PersonSheet: that person's open tasks as chips + Status poochho (`/ask #id`), Update, Done, Reassign, Due date, Description (`/desc #id `), Naya task, Mention. Every `@Name` inserted from a picker (or the inline `@` list) is remembered as `{id, label}` and sent as `mentionIds` (text order, also through the outbox); text is only inserted, the user taps send.
- **BotCard** (type `bot`): task event cards (all assignee names + avatars; Open hidden when I cannot view the task -> brief sheet; Undo of a created card = close; 👏 Praise), task picker, **userpicker** (tap sends `/cmd [pre] @First [arg]` with `mentionIds:[...keep, id]`), **ask** card (assignees get 6 status chips, Reply, Description = TaskActionSheet opened straight in the description editor), **reminder** card. Task / ask cards can be swiped right (or menu Reply) to reply: the server adds the reply as a note (`desc: ...` = new description, "ho gaya" etc. = status) ("N din se pending"), list, help, error, legacy summary/clarify/info.
- **Chat info** (GroupInfoScreen, every chat but check-in): big avatar (DM: the other person's emoji, phone, role), rename (groups, creator/boss), Mute + Pin switches, "Is chat ke tasks" / DM "Shared tasks" (brief rows not tappable; others open TaskActionSheet), members (Admin/Creator badges; tap = DM; remove icon for creator/boss), Add members (NewChatScreen mode `add`), Leave group; boss sees per-group `botEnabled / aiDetect / notifyAdmin` (`/admin/chats/:id/settings`).
- **Tasks tab**: segmented Overview | Board | List; filter Mine | Everyone for members (Everyone = BriefRow: title, status, names), Active | Closed for the boss. Board = 6 step columns (FlatList each). Rows show stacked avatars; long-press = TaskActionSheet (+ Undo alert after a status change, showing my own new step and the task's step); member list grouped Overdue / Due today / This week / Later; search accepts `#12`; ws `task` merges in place, summary/activity debounced 3 s. Overview top: members get **My day** (MyDay: counts Aaj diye / Done / Baaki, every task of today with the 6 status chips (my own status), note, Submit sign-off any time); the admin gets **Aaj ka sign-off** (per member, from `GET /admin/checkins`, live on ws `signoff`). Then **N+ din pending** (stale tasks; admin all, member own; TaskRow shows an `Nd` badge), tiles, Team rows, Activity. Board: Kanban. List: search + chips. "+" creates. Reloads on ws `task`, `task_deleted`, `task_stale`, `tasks_purged`, `reset`.
- **TaskDetail**: 403 -> "Ye task aap nahi dekh sakte". Title, aggregate status / Closed badge, People section (per-person status; my StatusChips; boss/creator tap a person to set theirs; Badlo = PeoplePickSheet), due, note, 👏 Praise, Close (reason) / Reopen (boss or creator), Copy `#id title`, timeline: rows with a source expand to the quoted message + "Chat mein dekho" (setPendingChat(chatId, messageId) + `_open_chat` with `messageId`: opens the chat scrolled to it).
- **Admin tab** (boss): "Settings" -> SettingsScreen: AI & Commands / Permissions / Notifications switches, AI status + Test AI, **Data retention** (switch + reminder / task delete / message delete days, Save days), App update fields, **Danger zone: Reset app data** (modal, type RESET -> `POST /admin/reset`). Settings, Reports and Check-in settings have their own green top bar and handle Android back (back to the Admin list). Then Reports / Check-in settings (morning card + evening sign-off times, days, reminder minutes), add member, members list, Background alerts. Members only see Account. Account (both roles): "Edit profile" (ProfileSheet: name + emoji, PATCH /auth/me). Admin member rows: emoji avatar, Edit profile, Reset PIN / new invite (logs the device out), Logout device.
- **Force update**: `checkVersion()` on start and every foreground (`GET /app/version`, no auth). `VERSION_CODE < minVersionCode` or any 426 `UPDATE_REQUIRED` -> full-screen `UpdateScreen` (message, Download opens `apkUrl`, Check again). `< latestVersionCode` -> dismissible banner. Bump `version.ts` + `app.json` (`version`, `android.versionCode`) together for each release.

## Notifications (local, no Firebase) and background
- `push.ts`: channels `messages` (high) and `tasks` (quiet). `listenMessageAlerts(userId, role)` notifies only when the app is not in the foreground: chat `message` (not mine; muted chats silent unless @mentioned; a slash command's own text never (its card / task event notifies); bot/system cards never, EXCEPT `ask` / `reminder` cards that mention me), `task` events (assignee: created / reassigned / praise; asker: answered; admin with `notifyAdmin`: completed / done / testing / change_merged, quiet). Foreground: InAppBanner instead. Notifications have an Android "Reply" text action (goes through the outbox as a reply), admin: `signoff` and `task_stale` (quiet). Tap opens the chat (`_open_chat`).
- Foreground service "TeamChat connected" (module `app/modules/teamchat-service`, `src/background.ts`) keeps the socket alive after swipe-away and reboot; Account tab "Background alerts" card. OnePlus needs App info -> Battery usage -> "Allow background activity". Details: projectProgess.md.
- Check-in reminders: local weekly notifications from `GET /checkins/today` settings (members only, `push.ts applyCheckinSchedule`).

## Realtime, outbox, live lists
- `realtime.ts`: one ws with backoff reconnect; `onEvent`; synthetic `_open` / `_close` / `refresh`. Events used: message, edited, deleted, read, typing, reaction, pin, chat, task, user, task_stale, tasks_purged, signoff, settings, users, purged, reset (open chat reloads; a reset closes group/DM chats).
- `outbox.ts`: AsyncStorage queue with `clientId` (server dedupes); flushed on send, reconnect and every 15 s in a chat; 4xx (not 401/429) drops the item. ChatScreen fetches `?after=<last server id>` on reconnect/foreground.
- `useLive.ts`: `useLiveRefresh(load, eventTypes)` (debounced; also on reconnect, `refresh`, foreground) + `usePullRefresh`. Rows are `React.memo`, lists windowed.

## Voice (mic)
`expo-speech-recognition` 1.1.1 (dev build only; hidden in Expo Go). Empty text box shows the mic; recording bar with waveform, language chip (hi-IN default / en-IN, saved in `voiceLang`), stop (text goes to the box) and send. Stops itself after 60 s. Nothing heard -> toast.

## Daily check-ins (members)
Private "Daily Check-in" chat (`type 'checkin'`): `checkin_prompt` messages render as `CheckinCard`: `day` = pinned list of my open tasks with my own status (overdue / N+ din tags; tap = TaskActionSheet; "+ Naya task"; updated live by the server). The `/` and task buttons also show in this chat, `signoff` = MyDay form for today (read-only counts for old days), old `morning`/`evening` cards = plain history. State from `checkinStore` (GET /checkins/today), submit `POST /checkins/signoff`. Boss reads sign-offs + typed notes in Admin -> Reports (day list with Sign-off pill + counts, member detail 7/30 days) and sets times in Check-in settings.

## How to collaborate
- New screen: `src/screens/X.tsx`; tab in `App.tsx`, or a view in `ChatsScreen` / `AdminScreen` / `TasksScreen`. Colors only from `useTheme()` (light + dark), 8pt spacing, tap targets >= 44.
- New API call: `api('GET', '/path')`; add types to `chatTypes.ts` / `taskTypes.ts`; document the endpoint in backend.md. New ws event: handle in `onEvent`.
